# Changelog

All notable changes to this project are documented in this file.

## [Unreleased]

### Added

- Authentication with refresh-token rotation, email verification and password reset
- Channels with avatar, banner, handle and verification badge
- Video and Shorts upload with background processing, visibility controls and view counting
- Likes and dislikes, threaded comments, subscriptions and notification preferences
- Playlists with Watch later and Liked videos system playlists
- Watch history with pause, remove and clear
- Real-time notifications over Socket.IO
- Search, trending and related video recommendations
- Studio analytics dashboard and admin moderation dashboard
- Demo data seed script with logo, icon and sample media assets
- Docker images, nginx configuration and GitHub Actions workflows
